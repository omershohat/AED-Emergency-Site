# מערכת לניהול קריאות מצוקה והפעלת דפיברילטורים חכמים

סימולטור אינטרנטי מתקדם לניהול מערך קריאות חירום והזנקת מתנדבים נושאי דפיברילטורים (AED). 
המערכת משתמשת ביכולות חיפוש מבוססות מיקום (Geo-fencing) כדי לאתר את המתנדבים הקרובים ביותר לזירת האירוע, מספקת להם ניווט ייעודי לשבילי אופניים, ועושה שימוש בסימולציה של רשת LoRa Mesh (דמוי Meshtastic) כערוץ תקשורת גיבוי לאזורים ללא קליטה סלולרית.

---

## טכנולוגיות ואדריכלות
המערכת בנויה בארכיטקטורת מיקרו-שירותים (Microservices) להפרדת סמכויות, יעילות ועמידות בעומסים:

- **Frontend (Web):** 
  אפליקציית צד-לקוח המבוססת על **Next.js (React)** ועיצוב באמצעות **Tailwind CSS**. מספקת ממשק משתמש למרכז שליטה (מפה), סימולטור, ומערכת הרשמה.

- **Identity & Registry API (פורט 4000):**
  שרת **Node.js (Express)** מול מסד נתונים רלציוני **MySQL 8**. 
  אחראי על ניהול משתמשים, רישום דפיברילטורים, ואבטחה באמצעות טוקנים (**JWT Authentication**).

- **Mesh & Dispatch API (פורט 5000):**
  שרת **Node.js (Express)** מול מסד נתונים **MongoDB**. 
  אחראי על טלמטריה (נתוני מיקום רציפים - Heartbeats), חיפושים מרחביים (Geo-fencing), ודחיפת נתונים בזמן אמת למרכז השליטה באמצעות **WebSockets**.

## מדריך התקנה לסביבת Windows

להרצת הפרויקט בסביבה מקומית (Localhost) על גבי מערכת הפעלה Windows, יש לעקוב אחר השלבים הבאים:

### 1. דרישות קדם (Prerequisites)
יש לוודא שהתוכנות הבאות מותקנות על המחשב:
- **Node.js** (גרסה 18 ומעלה)
- **MySQL Server** (ניתן להשתמש ב-WAMP, XAMPP, או התקנה ישירה)
- **MongoDB Community Server** (מומלץ להפעיל כשירות Windows)

### 2. הגדרת משתני סביבה (Environment Variables)
בתיקיות `api`, `mesh`, ו-`web` קיימים קבצי דוגמה (לרוב `.env.example`).
יש ליצור קובץ `.env` בכל אחת מהתיקיות האלו ולהזין את פרטי החיבור הרלוונטיים.
**חשוב:** יש לוודא כי המפתח הסודי (`INTERNAL_SERVICE_KEY`) זהה בשירותי ה-API וה-Mesh כדי לאפשר תקשורת מאובטחת ביניהם.

### 3. התקנת תלויות (Installation)
פתח את חלון הפקודות (Terminal / PowerShell) בתיקיית השורש של הפרויקט והרץ:
```bash
npm install
```
*(פקודה זו תתקין את כל התלויות הנדרשות עבור כל תיקיות הפרויקט בהתאם להגדרות ה-Workspaces).*

### 4. הגדרת מסדי נתונים והזנת נתוני סימולציה
יש להקים את סכמת מסד הנתונים ולהזין נתוני דמה (Seed) כדי לאפשר למערכת לדמות פריסת כוננים בזמן אמת.
בתיקיית השורש של הפרויקט, הרץ את הפקודות הבאות:

בניית הסכמה ב-MySQL:
```bash
npm run db:schema
```

הזנת נתוני סימולציה (כוננים, מכשירים ומיקומים) ל-MySQL ול-MongoDB:
```bash
npm run seed
```

### 5. הרצת המערכת (Execution)
להפעלת כל שירותי המערכת במקביל באמצעות פקודה אחת:
```bash
npm run dev
```

**פורטים בשימוש המערכת:**
- **Web Client (ממשק משתמש):** http://localhost:3000
- **API Server (זהויות):** http://localhost:4000
- **Mesh Server (טלמטריה):** http://localhost:5000
